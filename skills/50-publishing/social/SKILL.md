# Social

Help the user move from a specific audience question to useful content or an
account action. This skill covers organic Instagram, Facebook Pages, LinkedIn,
YouTube, TikTok, Reddit, and Pinterest. Paid campaigns belong to Ads; Discord,
Slack, and WhatsApp Business messages belong to Channel Messaging.

Start with the user's goal, intended reader, evidence, offer or point of view,
available assets, and account constraints. Reuse supplied documents and results.
Do not connect an account for advice, a draft, or an edit. Public research is a
separate, potentially billable request; select only the sources and sample size
needed to answer the question. Never treat public engagement as evidence of
sales or infer a platform's current ranking rules from a few posts.

## Work from evidence to an action

For recommendations, distinguish observed facts, an interpretation, and a
testable hypothesis. Identify the audience problem and the one response the
content should earn. Draft in the user's voice; keep real numbers, names,
testimonials, images, and product claims tied to supplied or cited evidence.
Adapt the same idea to each platform's reading context instead of posting an
identical block everywhere. Give a ready-to-review draft with the proposed
account, format, asset, link, visibility, and expected next step.

For an account operation, follow [channel execution](references/channel-execution.md):
reuse the user's connection, inspect the current tool schema, bind the exact
account and object, and preserve the first result. Connection alone is not
authorization to publish. Before a write, show the destination and final copy,
media, visibility, or reply target and use the authorization already given for
that exact operation. If essential scope is missing, ask for that scope. After
submission, distinguish request accepted, platform processing, visible result,
and unknown result. An unknown write is checked under its original operation
ID; it is never repeated with a fresh ID.

Close with the requested artifact or the verified result, what remains
uncertain, and the next decision. If a source or platform capability is absent,
say what evidence is missing instead of inventing a collection or publishing
path.
