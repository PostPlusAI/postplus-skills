# Street Interview

Adapt supplied street interviews into a complete shot script or requested AI video.
Read [reference adaptation](references/reference-adaptation.md) for faithful scene,
action and dialogue handling, prompt review, asset bindings and production handoff.
Use `media-analysis` for a new source analysis and `video-batch-runner` for approved
generation; the usual reference endpoint is `video-seedance-2-5-reference`.

Read only the matching format:
- [Blind test](references/blind-test.md)
- [Problem to replacement](references/problem-to-replacement.md)
- [Playful challenge](references/fun-challenge.md)

Present the concrete prompt in the user's language for approval. Preserve the
complete exchange; leave captions and other overlays for postproduction unless
the user explicitly requests them in generated footage.
