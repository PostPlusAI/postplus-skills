# Reference evidence and adaptation fidelity

When the user also requests faithful recreation or adaptation, carry the
chronological observations into that work with their evidence limits. Preserve
concrete framing, cuts, action order, simultaneous actions, full supported
dialogue and delivery; do not replace an exchange with a label such as
"natural reaction". A supported smile before "Uh... sure...", then laughter
while the host waits and retrieves the microphone is a sequence, not just an
affirmative answer.

Keep source observations, verified target-product facts and creative changes
distinguishable. Record source captions, stickers and other overlays as observed without
automatically turning them into generation instructions. The downstream
generation skill follows the user's adaptation and postproduction choices and
selects which assets, if any, to submit. This handoff uses the existing evidence; it does not
require a separate report or another analysis run.
