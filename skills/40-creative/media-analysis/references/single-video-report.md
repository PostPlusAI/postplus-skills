# Video report

Every video uses the same server-owned full-timeline prompt through CLI or MCP.
It requests detailed timestamped visual, camera, editing, action, prop/product,
speech, screen-text and sound observations across the original timeline.
Original verbatim audio and on-screen subtitles are separate tracks, including
interjections, repetitions, pauses, corrections, laughter and overlapping voices.
Unobservable or uncertain content must be identified, never guessed.

Deliver the model Markdown unchanged. The prompt aims for rich, faithful evidence;
it does not guarantee lossless, pixel-perfect or omission-free perception.
No extra Agent review, summary, strategy section or paid quality rerun is required.
Separately requested interpretation uses this original record as its source.
